数据模型 & 边界情况

材质映射表结构 (JSON/CSV)

{|
│ "su_material_name": "tile_302", ← SU材质名（唯一标识）
│ "material_name": "马可波罗灰砖", ← 真实材料名称
│ "category": "瓷砖", ← 分类：瓷砖/石材/涂料/木材/墙纸/玻璃/金属/其他
│ "unit": "m²", ← 计量单位
│ "spec": "600×600", ← 规格描述（可选）
│ "default_waste_rate": 0.05 ← 默认损耗率
|}

▶ 用户可批量导入CSV
▶ SU材质名重复时提示覆盖
▶ 支持按分类批量设置损耗率

空间识别规则

通过SU的层级结构自动识别空间：

方案一（推荐）：按 组件/群组 层级划分
└ 模型根
└ 客厅 (组件/群组)
├ 墙面 → 读取材质
└ 地面 → 读取材质
└ 主卧 (组件/群组)
├ 墙面 → 读取材质
└ 地面 → 读取材质

方案二：按 SU图层 划分
每个空间或面放在对应图层，插件按图层分组统计

运行时用户可选择分组方式，也可以不分组汇总

边界情况处理

!
无材质的面 — 扫描时检测到未赋材质的透明面，在结果中标记为"未指定"，允许用户手动映射或忽略
!
隐藏面/背面 — 自动跳过隐藏几何体和背面（法线朝下的面），用户可配置是否计入
!
曲面 — SU的曲面由多个小面构成，分别读取每个面的材质和面积求和，支持网格面的精确统计
!
"手动标记面"补充 — 对于未建入模型的面（如踢脚线），用户选取一个面后通过对话框填写材料和面积，计入统计
!
同一模型多个相同材料 — 自动合并同名材质的面积再汇总，确保不重复统计
