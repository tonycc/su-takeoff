# SU Takeoff 业务实现逻辑

本文档描述插件从启动到输出最终报表的每一步业务处理规则、判定依据和数据流转，不涉及代码实现细节。

---

## 一、初始化

### 1. 加载数据文件

系统启动时从 `data/` 目录加载三项配置数据，如果缺失则使用空默认值：

**材料映射表（default_mapping.json）**
- 作用：建立「SU 原生材质名」到「工程材料名」的对照关系
- 每条记录包含：SU 材质名、真实材料名、材料分类、计量单位、规格型号、默认损耗率
- 初始由人工通过 CSV 导入或手动录入维护

**工艺库（default_processes.json）**
- 作用：按材料分类存储不同施工工艺及其对应损耗率
- 例如：石材分类下可有「干挂」（损耗率 8%）、「湿贴」（损耗率 5%）等多种工艺
- 每种分类可包含多个工艺，每个工艺有独立的损耗率

**忽略材质列表（ignored_materials.json）**
- 作用：记录用户在审核阶段标记为「忽略」的 SU 材质名
- 被忽略的材质在统计时不会被要求映射，也不会参与面积计算
- 自动维护，无需手动编辑

### 2. 注册操作入口

在 SketchUp 的 Plugins 菜单下创建「SU Takeoff」子菜单，以及一个同名的工具栏按钮。两者均打开同一个操作面板。

## 二、模型扫描

用户点击「扫描全部」或「仅选中面」开始扫描。扫描只做一件事：**从模型中提取所有面的几何信息与材质信息**，不做任何计算。

### 3. 确定扫描范围

- **扫描全部**：遍历当前打开模型中所有可见实体
- **仅选中面**：仅遍历用户当前选中的实体。如果没有任何选中，自动退化为扫描全部

### 4. 递归遍历实体结构

SketchUp 模型中的实体是树状层级结构：面（Face）是最小单元，它们可以嵌套在群组（Group）或组件（ComponentInstance）中。扫描器递归进入每一层，累计记录以下信息：

- **面在空间中的位置**：通过累积每一层群组/组件的变换矩阵，将坐标统一到世界坐标系
- **面所属的空间**：记录面的所有祖先组件/群组名称列表，最后一级通常为房间名（如「客厅」「主卧」）

### 5. 提取面的基本信息

对每一个面，采集以下原始数据：

| 信息项 | 说明 | 业务用途 |
|--------|------|---------|
| 材质名 | 面的正面或背面材质的名称；可能为空（未赋材质） | 后续材料映射的依据 |
| 材质颜色 | 材质的 RGBA 值 | 前端 UI 展示色块，方便用户辨认 |
| 面积 | 面的真实面积，换算为平方米 | 用量统计的基础数据 |
| 法向量 | 面在世界坐标系中的朝向 | 判断面属于地面、墙面还是天花 |
| 中心高度 | 面 bounding box 中心点的世界 Z 坐标（米） | 薄板去重时判断板的位置 |
| 宽高估算 | 面 bounding box 的次大边和最大边尺寸 | 参考信息，当前未用于计算 |
| 图层名 | SU 图层名称 | 辅助分类 |
| 所属空间 | 父级组件/群组名称列表 | 统计时按空间分组 |

### 6. 识别门窗洞口（规则一：透明度）

当面的材质 alpha（透明度）值小于 0.5（即半透明或全透明），判定该面为**玻璃类洞口**。该面本身不参与后续统计。

业务假设：模型中的窗户玻璃使用透明材质，alpha < 0.5 是合理区分阈值。

### 7. 识别门窗洞口（规则二：组件命名）

当组件/群组的**定义名称**（definition name）包含以下关键词时，该组件内的所有面均被标记为洞口：

- 英文：`window`、`door`
- 中文：`窗`、`门`

匹配不区分大小写。

**注意**：命名规则匹配的是组件定义名（定义模板的名称），而非场景中实例的名称。例如组件定义叫「推拉窗」，场景中 50 个实例都会被识别。

### 8. 跳过不可见面

以下情况的面直接跳过，不计入任何统计：
- 被隐藏的面（hidden）
- 不可见的面（visible 为 false）

### 9. 合并人工标注面

扫描结果中还合并了一类特殊数据：**人工标注面**。

当模型中的面没有赋材质，或者用户需要覆盖默认映射时，可以使用「手动标记面」功能。标记信息保存在面的属性数据中，包含：
- 用户指定的材料名称
- 部位（地面/墙面/天花）
- 所属空间
- 损耗率

扫描时读取所有有标记数据的面，将其作为额外的扫描条目汇入，参与后续统计。

## 三、审核阶段

扫描完成后进入审核。审核阶段的核心任务是：**将模型中出现的每种 SU 材质，逐一确认其工程材料对应关系或排除出统计范围**。

### 10. 统计材质清单与状态

汇总扫描到的所有不同材质名，逐一判定状态：

| 状态 | 条件 | 含义 |
|------|------|------|
| 已映射 | 映射表中存在对应记录 | 知道这是什么材料，可直接统计 |
| 已忽略 | 在忽略列表中 | 这种材质不需要统计（如辅助线、参考面） |
| 待处理 | 以上两条都不满足 | 需要用户决定：映射成什么？还是忽略？ |

### 11. 提供材质上下文辅助判断

对每种材质，系统自动整理上下文信息，帮助用户判断这是什么材料：

- **面数**：该材质在模型中共出现在多少个面上
- **总面积**：所有使用该材质的面的面积之和
- **部位分布**：分别有多少面积属于地面、墙面、天花
- **空间分布**：出现在哪些房间（取面积最大的前 3 个）
- **颜色色块**：材质的颜色，方便用户通过视觉辨认

### 12. 自动推测材料分类

当用户为新材质填写映射时，系统根据材质名关键词自动推测分类：

| 关键词 | 推测分类 |
|--------|---------|
| tile、瓷砖、砖 | 瓷砖 |
| marble、stone、石、大理石 | 石材 |
| paint、漆、涂、乳胶 | 涂料 |
| wood、木 | 木材 |
| wallpaper、墙纸、壁纸 | 墙纸 |
| glass、玻璃 | 玻璃 |
| steel、metal、金属、铁、钢、铝 | 金属 |
| 石膏板、龙骨、找平 | 其他 |

仅为辅助性默认值，用户可手动更改。

### 13. 映射与忽略操作

用户可逐个处理待定材质：

- **映射**：指定该 SU 材质对应的真实材料名、分类、规格、损耗率 → 保存到映射表并持久化
- **忽略**：将该材质加入忽略列表 → 后续统计完全跳过

支持批量操作：一键将所有待处理材质按 SU 材质名填充为「材料名 + 默认分类 + 5% 损耗」然后批量保存；或一键将剩余所有待处理材质标记为忽略。

### 14. 定位材质对应的面

系统可选中模型中使用某种材质的所有面，并缩放视图至这些面，方便用户通过视觉确认材质用途。

遍历范围：递归进入所有群组和组件内部查找匹配的面。

## 四、统计计算

所有材质均已映射或忽略后，进入统计计算阶段。

### 15. 区分面属于哪个部位

根据面的法向量（朝向），将每个面归入三个部位之一：

| 判定条件 | 结果 |
|---------|------|
| 法向量指向正上方（与竖直方向夹角 < 30°） | 地面 |
| 法向量指向正下方（与竖直方向夹角 < 30°） | 天花 |
| 法向量接近水平（与竖直方向夹角 ≥ 30°） | 墙面 |

阈值选用 cos 30° ≈ 0.866，即法向量与 Z 轴的夹角在 30° 以内视为水平面。

### 16. 薄板去重

**业务背景**：设计师通常将楼板或天花建模为有厚度的体（如 10cm 厚的板）。这样的板有顶面和底面，两个面使用同一种材质。如果不处理，统计时会把底面也当作用量，导致该板材的面积翻倍。

**判定逻辑**：
1. 在同一空间、同一材质的面中，寻找法向朝上和朝下的水平面对
2. 如果一对面的面积几乎相等（差异不超过 2%）、且高度差不超过 15cm，则判定为同一块板的两面
3. 根据这块板在空间中所处的垂直位置决定保留哪一面：
   - 板在空间下半部分 → 保留朝上的面（地面可见面），删除底面
   - 板在空间上半部分 → 保留朝下的面（天花可见面），删除顶面

「空间下半部分」的判断依据：计算该空间所有面的 Z 坐标最大最小值的中位线，板中心低于中位线视为下半部分。

### 17. 跳过未映射材质

任何未在映射表中建立对应关系、也未在忽略列表中的材质，其对应面不参与统计计算。系统在审核阶段已确保这一情况不会发生——如果存在未处理材质，会阻止进入计算阶段。

### 18. 按空间-部位-材质分组汇总

以 `[空间名, 部位, SU材质名]` 三个维度为键，将面分组：
- 同一面被同时计入一个且仅一个组
- 空间名取面所在的最深层组件名；如果面无父组件，归入「未分组」
- 对于每组，计算净面积 = 组内所有面的面积之和
  - 每个面扣减对应的门窗洞口面积（如有），且不出现负数（与 0 取最大值）
  - 当前实际运行中洞口面已在扫描时直接排除，扣减逻辑存在但未执行

### 19. 确定损耗率并计算采购量

对每个分组，确定其损耗率：

- 默认使用材料映射表中配置的损耗率（如 5%、8%）
- 如有指定施工工艺，则使用该工艺的损耗率

采购量 = 净面积 × (1 + 损耗率)，结果四舍五入到小数点后两位。

### 20. 按材料跨空间汇总

将上一步的分组结果进一步汇总：以真实材料名为键，合并所有空间、所有部位的同材料用量，得到每种材料的：

- 总净面积（所有空间、所有部位之和）
- 总采购量（含损耗后之和）

### 21. 输出三种统计视图

**按空间汇总**（默认视图）：
- 每行：空间、部位、材料名、净面积、损耗率百分比、采购量、规格
- 例如：「客厅 / 地面 / 马可波罗灰砖 / 27.0 m² / 5% / 28.35 m² / 600×600」

**按材料汇总**：
- 每行：材料名、总净面积、总采购量
- 例如：「马可波罗灰砖 / 47.0 m² / 49.35 m²」
- 数据来源：上一步跨空间汇总结果

**展开明细**：
- 每行：空间、部位、材料名、面积、SU 原始材质名
- 比按空间汇总省略了损耗率和采购量，增加了 SU 原始材质名
- 用于追溯每条数据来源于模型中哪个 SU 材质

## 五、辅助功能

### 22. 人工标记面

允许用户直接对模型中的面进行材质标注，覆盖或补充自动扫描结果。

**使用场景**：
- 面没有赋材质，但实际需要计算为某种材料
- 自动材质映射的结果不准确，需要手动纠正

标注时需指定：材料名称、所属部位（地面/墙面/天花）、所属空间、损耗率。标注数据写入模型文件内部，随模型保存。

### 23. 定位某个材质的全部面

用户点击定位按钮后，系统自动在当前模型中查找使用该 SU 材质的所有面，将它们选中并缩放视图。查找范围覆盖整个模型实体树（包括嵌套的组件和群组内部）。

### 24. 映射表维护

映射表独立于扫描和统计，可随时编辑：

- **手动增删**：输入 SU 材质名和对应材料信息
- **CSV 导入**：批量导入 6 列格式的映射文件
- **CSV 导出**：将当前全部映射导出为 CSV 文件用于备份或交换
- **搜索过滤**：按 SU 材质名模糊搜索现有映射记录

## 六、核心业务假设与边界

| 假设 | 说明 |
|------|------|
| 30° 角度阈值 | 法向量与竖直方向夹角在 30° 以内判定为水平面（地面/天花），否则为墙面。该值对应现实中允许的建模偏差 |
| 2% 面积容差 | 薄板去重时，两面面积差异不超过 2% 视为同一块板 |
| 15cm 厚度容差 | 薄板去重时，两面高度差不超过 15cm 视为同一块板。覆盖常见楼板（8-12cm）+ 建模误差 |
| 0.5 透明度阈值 | 材质 alpha < 0.5 判定为透明玻璃类材质 |
| 空间归属 | 空间名=面所在的最深层组件名。不识别层级嵌套（如「一楼/客厅」） |
| 面积单位 | 模型内尺寸为英寸，统一换算为 m²（1 in² = 0.00064516 m²） |

## 七、结果验证要点

评估统计结果是否准确，应从以下方面校验：

1. **面采集完整性**：是否存在遗漏的面（隐藏除外）、是否因跳过不可见面而缺失、标注面是否全部被采集到
2. **面积准确性**：组件/群组内的面面积是否正确计入缩放变换后的大小
3. **部位判定准确性**：倾斜面（如坡屋顶、楼梯）是否被归入正确的部位
4. **薄板去重正确性**：是否误删非薄板的面、是否遗漏真正的薄板背面
5. **洞口处理**：透明玻璃是否被排除、门窗组件是否被排除、排除时是否影响了周围的墙面积
6. **材质映射完整性**：模型中出现但未映射的材质是否正确拒绝进入计算
7. **损耗率应用**：每种材料的损耗率来源是否正确（默认 vs 工艺覆盖）
8. **汇总一致性**：按空间、按材料、明细三种视图的数据是否一致（明细面积之和 = 按材料视图的净面积）
