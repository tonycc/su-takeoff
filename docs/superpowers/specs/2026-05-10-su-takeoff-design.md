# SU Takeoff — 装修面材用量统计插件 设计文档

## 概述

SketchUp 插件，自动统计装修面材的使用量，面向装饰公司的报价场景。通过读取 SU 模型中的材质信息并映射为真实材料名称，自动扣除门窗洞口，按空间×部位输出精准的材料采购量。

## 核心工作流

```
SU 模型 → 材质扫描器 → 材质映射引擎 → 统计计算引擎 → 报表生成器
                                              ↕
                                        手动标记面
```

1. **材质扫描器** — 遍历模型所有面，读取 SU 材质信息，按面计算面积
2. **材质映射引擎** — SU 材质名 → 真实材料名、分类、规格、默认损耗率
3. **统计计算引擎** — 按空间分组、按部位分类、合并同名材质、应用损耗率
4. **报表生成器** — 输出 SU 内嵌表格 + Excel 导出（模板待定）

## 四大模块

### 1. 材质扫描器

- 遍历模型所有面（Face 对象），读取材质（material.name）
- 计算每个面的精确面积
- 自动跳过隐藏几何体和背面
- 曲面由多个小面构成，分别读取并求和
- 无材质的面标记为"未指定"并在结果中标红
- 支持范围选择：扫描全部 / 仅选中面
- **自动扣除门窗洞口：** 识别模型中的门窗组件/开口，从墙面/天花净面积中扣除对应洞口面积。识别策略：检测组件内的开口面、透明面材质，或通过嵌套组件的边界关系判断洞口范围。

### 2. 材质映射管理器

管理 SU 材质名 → 真实材料的映射关系。每条记录包含：

| 字段 | 说明 |
|------|------|
| su_material_name | SU 材质名（唯一标识） |
| material_name | 真实材料名称 |
| category | 分类：瓷砖/石材/涂料/木材/墙纸/玻璃/金属/其他 |
| unit | 计量单位（默认 m²） |
| spec | 规格描述（如 600×600、18L/桶），可选 |
| default_waste_rate | 默认损耗率 |

- 支持导入/导出 CSV 批量编辑
- 未映射的材质在统计表中标红高亮
- SU 材质名重复时提示覆盖
- 支持按分类批量设置损耗率

**工艺匹配：** 每个材料可关联多种施工工艺，不同工艺对应不同损耗率。

| 材料 | 可选工艺 | 对应损耗率 |
|------|----------|-----------|
| 瓷砖 | 密缝铺贴 / 留缝铺贴 / 斜铺 / 人字拼 | 5% / 5% / 15% / 20% |
| 石材 | 干挂 / 湿贴 | 5% / 8% |
| 墙纸 | 对缝 / 不对缝 | 10% / 5% |

- 用户在映射管理 Tab 中为材料配置默认工艺
- 统计时可临时切换工艺，实时更新采购量
- 工艺库可编辑扩展

### 3. 统计计算引擎

**空间识别：** 通过 SU 的组件/群组层级自动识别空间名称。用户可选择按 SU 图层分组或不分组汇总。

**部位识别：** 根据面的法线方向自动判断：
- **地面** — 法线朝上（Z 正方向 ±30°）
- **墙面** — 法线水平（与 Z 轴夹角 60°~120°）
- **天花** — 法线朝下（Z 负方向 ±30°）
- 用户可手动修正误判的面

**计算规则：**
- 净面积 = 各面面积之和
- 采购量 = 净面积 × (1 + 损耗率%)
- 同空间同材料在不同部位分行显示，不合并

**手动标记面：** 对于未建入模型的面或需要补记的面，用户选中 SU 面后通过对话框指定材料、部位、空间、损耗率，计入统计。被标记的面在 SU 中高亮显示并附带标签，修改模型后标记保留，支持增量更新。

### 4. 报表生成器

SU 内嵌 HTML 对话框展示统计结果，三个视图可切换：

1. **按空间汇总** — 按空间+部位分组，列出每个部位的材料和采购量
2. **按材料汇总** — 所有空间相同材料合并，算出总采购量
3. **展开明细** — 每个面的面积、尺寸、SU 材质 ID、SU 面 ID

**导出：** 等待核心功能完成后按特定模板实现，当前版本不设计导出格式。

## UI 结构

SU HTML 对话框，三个 Tab：

### Tab1: 统计

- 工具栏：扫描全部 / 仅选中面 / 手动标记面
- 统计表（列）：空间 / 部位 / 材料 / 净面积(m²) / 损耗率 / 采购量(m²) / 规格
- 视图切换按钮：按空间汇总 / 按材料汇总 / 展开明细
- 导出按钮（后续实现）

### Tab2: 映射管理

- 搜索框
- 导入 CSV / 导出模板 按钮
- 映射表（列）：SU 材质名 / 真实材料名 / 分类 / 单位 / 规格 / 默认损耗率 / 操作
- 未映射行红色高亮

### Tab3: 设置

当前版本的设置 Tab 不纳入初始实现。损耗率、空间识别规则等参数在映射管理 Tab 和手动标记对话框中配置即可。

## MVP 范围

### 包含
- 空间感知（SU 组件/群组层级识别房间）
- 天/地/墙净面积统计
- 自动扣除门窗洞口
- 材质映射管理（SU 材质→真实材料名、分类、规格）
- 工艺匹配（下拉选择 → 自动匹配损耗率）
- 手动标记面补漏
- 异常预警（未映射材质标红）
- 三个视图切换（按空间汇总 / 按材料汇总 / 展开明细）

### 不包含（后续版本）
- 踢脚线长度计算
- 阴阳角数量统计
- 辅料联动（水泥/砂浆/胶水）
- Excel 导出（按特定模板，后续实现）
- 独立 Web 应用界面（使用 SU 内置 HTML 对话框）

## 边界情况

| 情况 | 处理方式 |
|------|----------|
| 无材质的面 | 标记为"未指定"，允许用户映射或忽略 |
| 隐藏面/背面 | 自动跳过，用户可配置是否计入 |
| 曲面 | 由网格面构成，分别读取材质和面积求和 |
| 门窗洞口 | 识别门窗组件中的开口，从所属墙面/天花的净面积中扣除 |
| 手动标记面 | 模型修改后标记保留，增量更新 |
| 同名材料 | 按空间+部位分行，不合并 |

## 技术约束

- 平台：SketchUp（Ruby API + HTML 对话框）
- 材质映射数据格式：JSON/CSV
- 页面交互：SU 内嵌 HTML 对话框（WebDialog）
