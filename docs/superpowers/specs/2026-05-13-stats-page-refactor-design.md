# 统计页面交互重构 — 设计文档

## 目标

重构统计 Tab 的交互模型，从"阶段推进"改为"同页多视图"。扫描一次得到原始数据，用户在三个视图间自由切换：组件视图（默认）看模型结构与面级明细，材料视图就地完成映射，采购量视图查看下单数字。映射不再是阻塞性阶段，而是可随时增量编辑的字段。

## 背景与动机

当前实现采用 Phase 1（扫描）→ Phase 2（映射）→ Phase 3（统计）线性阶段。已发现的问题：

- **按组件视图入口藏得太深**：所有材质映射完成前走不到 Phase 3。
- **Phase 1 和 Phase 3 职责重叠**：两者都在展示组件维度的数据。
- **数据可能不一致**：Phase 1 显示未去重数据，Phase 3 显示 Calculator 处理后数据。
- **映射必须一次性完成**：现实中用户常需要增量映射。

### 关键变化

- **取消 Phase 1/2/3 分页切换**：扫描完所有视图即时可用。
- **扫描入口常驻**：可随时重新扫描，替换当前结果。
- **摘要条是状态枢纽**：数字实时反映数据；点击"待 X"跳转到材料视图并筛选。
- **视图切换不重置状态**：滚动、展开、筛选条件保留。
- **其他标签页保留**：映射 tab 仍是映射库管理，设置 tab 不变。

## 视图：按材料（就地映射）

SU 材质为行，直接编辑映射字段，取代当前 Phase 2 的 review 表。

```
[全部] [待映射(16)] [已映射(3)] [已忽略(0)]  🔍[搜索...]
├───────────────────────────────────────────────────────────────
状态 │ SU材质（色）   │ 面数/面积 │ 部位分布  │ 真实材料 │ 分类 │ 损耗 │ 忽 │ 🎯
──────────────────────────────────────────────────────────────
 ✓  │ ■ 瓷砖-灰      │ 12/37.8m² │ 地:25 墙:12│ 瓷砖灰600 │ 瓷砖 │ 5%   │ □ │ 🎯
 ●  │ ■ Material#-21 │  8/25.5m² │ 地:12 顶:12│ [____]   │[其它]│ 5%   │ □ │ 🎯
 ○  │ ■ 涂料-白      │526/37.8m² │ 全部墙面   │ —        │ —    │ —    │ ■ │ 🎯

[一键填默认] [保存映射] [全部忽略]
```

**字段说明：**
- **状态**：✓ 已映射（绿）/ ● 待处理（红）/ ○ 已忽略（灰）
- **映射字段**：真实材料名、分类、规格、损耗率——已映射行只读，待处理/已忽略行可编辑
- **忽略复选**：直接勾选切换忽略状态
- **🎯 定位**：高亮 SU 中使用该材质的所有面

**筛选栏：**
- 默认「全部」
- 点「待映射(N)」只看未处理的
- 摘要条"待 N"点击跳到此视图 + 应用该筛选

**批量操作：**
- 「一键填默认」：把所有待处理行的真实材料名填为 SU 材质名
- 「保存映射」：提交已填写的行（保存后立即触发 Calculator 重算）
- 「全部忽略」：把所有待处理标为忽略

## 数据流与响应式

### 数据分层

```
原始层（扫描得到，不可变）:
  items: ScanItem[]         所有面
  openings: Opening[]       洞口

可变层（用户编辑）:
  mapping: MaterialMapping  SU材质 → 真实材料
  ignored: string[]         忽略列表

派生层（自动计算）:
  usages: MaterialUsage[]   Calculator 输出（含采购量）
```

### 何时重算

| 触发 | items | openings | usages |
|---|---|---|---|
| 扫描全部 / 仅选中 | 重新生成 | 重新生成 | 重新生成 |
| 保存映射 / 切换忽略 | 不变 | 不变 | **重新生成** |
| 映射 tab 增删映射记录 | 不变 | 不变 | **重新生成** |
| 视图切换 | 不变 | 不变 | 不变 |

映射变更后 Ruby 端立即重跑 Calculator，把新 usages 推送给前端，所有视图按需重绘。

### 视图数据依赖

```
组件视图    ← items（构树）+ usages（采购量列）
材料视图    ← items（按 SU 材质分组）+ mapping + ignored
采购量视图  ← usages
摘要条     ← items.count + mapping.count + ignored.count
```

切换视图不触发 Ruby 调用，前端缓存 items 和 usages 仅重绘 DOM。

### 首次加载（未扫描）

所有视图显示空态提示：
```
🔍 请先点击「扫描全部」或「仅选中面」
```

### 错误处理

- **Calculator 计算失败**：视图显示错误提示 + 重试按钮，不清空 items
- **映射保存失败**（磁盘错误）：弹框告知，本地状态回滚

## 影响范围

### 不改动

- `data_models.rb`、`scanner.rb`、`calculator.rb`、`mapping.rb`、`process_library.rb`、`marker.rb`、`main.rb`
- 映射 tab（映射库管理）、设置 tab
- 数据模型已支持的 `component_path_ids` 与部位徽标

### 改动

| 文件 | 改动 |
|---|---|
| `src/ui/dialog.rb` | 合并 Phase 的数据推送逻辑；新增映射变更后自动重算+推送 usages |
| `src/ui/index.html` | 删除 phase-scan/phase-mapping/phase-stats 三个卡片；改为统一工作台结构 |
| `src/ui/app.js` | 删除 phase 切换；组件/材料/采购量三个视图渲染函数；摘要条与筛选栏交互；视图间状态保留 |
| `src/ui/styles.css` | 摘要条、筛选栏、采购量视图警告条等新样式 |

## 非目标（YAGNI）

- 不重新设计 Calculator 输出结构
- 不添加新的数据导出格式（CSV/Excel 在当前能力范围内）
- 不支持多模型对比
- 不保留 Phase 切换作为兼容模式
