# 发布说明

## v1.1.0

### 新增

- 新增项目绑定页面，支持平台项目选择、项目绑定和算量推送。
- 新增系统管理页面，集中展示软件版本、登录账号、租户、推送权限并提供退出登录。
- 插件入口新增独立登录页和登录门禁：打开后先校验登录状态，未登录时锁定扫描、映射、参数管理、定位和标签写入等功能。
- 新增开发调试 loader：SketchUp 可直接加载当前源码目录，开发版菜单显示为 `SU Takeoff Dev`，无需反复打包 RBZ。
- 新增项目绑定，保存平台项目编号、项目名称、模型标识和最近同步结果到模型 AttributeDictionary。
- 新增 SU 智能算量协议 v2 payload 构建，支持稳定编码、材料标签校验、面积扣洞口、长度/体积/件数 Part 聚合和幂等键生成。
- 新增后台推送服务，支持 401 refresh 后重试一次、429/5xx/网络错误有限重试，以及最终失败写入本地 outbox。
- 材料映射新增 `platform_material_tag`，组件映射新增 `platform_material_tag` 和 `platform_component_type`。
- Scanner/ScanItem 增加 persistent id 字段，用于平台稳定编码，原 entityID 定位能力保持不变。

### 修复

- 修复算量推送恒返回 500 的问题：`QuantityPayloadBuilder` 生成的 `source_version` 为 `sha256:<完整64位hash>`（71 字符），超过服务端 `source_version` 字段 64 字符上限，触发服务端未捕获异常返回 500。现截断为 `sha256:<hash前16位>`（23 字符，与 `idempotency_key` 截断一致），内容派生且稳定，不影响幂等键。
- 适配服务端 FastAPI 错误响应格式：`ApiClient#raise_error_from_response` 增加 `detail` 信封解包，支持业务错误（`{"detail": {"code", "message"}}`）和 422 校验错误（`{"detail": [{type, loc, msg}]}`）两种格式。修复前所有业务错误码退化为 `HTTP_XXX`，多租户登录（`TENANT_SELECTION_REQUIRED`）不可用。
- `AuthSession#tenant_options_from` 兼容 FastAPI 信封，从 `body['detail']['available_tenants']` 正确提取租户列表。
- 登录会话安全存储按 API 环境和域名隔离，避免开发、生产环境同名账号的 refresh token 互相覆盖。
- 登录流程增加整体超时保护，macOS Keychain 读写也增加超时保护，避免系统安全存储或网络异常时页面一直停留在「正在登录」。
- 登录后台线程改为通过 UI 队列泵回传结果，并增加 UI 线程看门狗超时；即使网络线程无法正常回调 HtmlDialog，也会恢复按钮并显示超时错误。
- 登录错误提示增加中文化处理，避免网络异常、401、422、服务端错误等英文异常直接显示给用户。
- 登录错误提示补充 `Invalid credentials` 等英文凭证错误映射；登录中状态文案改为「正在登录...」，不再展示等待秒数。
- 云端页面前端展示层增加错误兜底翻译，避免绕过 Ruby 错误处理的英文提示直接渲染。
- 开发模式下 HtmlDialog 每次打开都会给 CSS / JS 自动追加时间戳，减少 SketchUp Chromium 缓存导致“重新加载后没变化”的情况。

### 配置

- 新增 `data/api_config.json` 保存 API 环境和 Base URL。当前生产配置为 `https://gzzyai.com`。
- 生产 HTTPS Base URL 已确认为 `https://gzzyai.com`（服务名 `ai-interior-api`）。

### 验证

- 单元测试通过：`210 runs, 428 assertions, 0 failures`。
- 生产测试账号登录、`/identity/me` 自检和 `quantity:ingest` 权限验证通过。
- 生产环境端到端联调通过（`tools/integration_check.rb`）：首次推送成功返回 `sheet_id`/`model_version_id`；相同 payload 二次推送 `sheet_id` 与 `model_version_id` 完全一致（幂等去重生效）；20000 组件 / ~3.5MB 大 payload 服务端接受（未触发 413）。
- RBZ 打包检查通过，包内已包含 `src/api/`、`src/ui/js/cloud_sync.js` 和 `data/api_config.json`。

### 待联调

- 服务端 `source_version` 上限 64 字符（联调实测 64→200 / 65→500），且超长返回未捕获 500 而非 422：建议服务端补充长度校验。`code`/`material_tag`/`idempotency_key` 的精确上限未逐项压测（实测 59 字符 idempotency_key 正常）。
- 单次 payload 上限未探到：20000 组件 / ~3.5MB 可通过，确切字节数/数组数量上限仍待确认。
- 多租户选择分支（`TENANT_SELECTION_REQUIRED`）当前测试账号为单租户，仅由单测覆盖，需多租户账号线上复验。
- 大模型超时、网关限制、Windows 安全存储和重启恢复仍需专项验证。
