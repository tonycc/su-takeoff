# 策略模式架构优化实施方案

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `method` 枚举（`:area/:length/:volume/:count/:skip`）升级为 Strategy 对象，让"同一计量方式的不同算法"成为一等公民，使新增组件/算法/计量方式不需要改散落多处的 case/when。

**Architecture:** 三层模型 ——
1. **TakeoffStrategy** 对象封装"一种算量方式"（method + unit + emit + aggregate）
2. **GeometryCalculator**（如 LengthCalculator）封装"具体几何算法"，可被多个 Strategy 复用
3. **StrategyRegistry** 单例集中注册，**Policy 决议链返回 Strategy 而非 method**

**用户感知零** —— UI、AttrDict、mapping 表全部保持现状。Strategy 是开发者扩展点，匹配靠系统约定（命名规则、unit、图层），用户不直接选。

**Tech Stack:** Ruby 2.6（SketchUp 内嵌），Minitest，无外部依赖。

---

## 背景

### 当前痛点

`method` 枚举在 6 处独立 case/when 散落：

| 文件 | 行 | 责任 |
|---|---|---|
| `src/takeoff_policy.rb` | 121 | unit → method 决议 |
| `src/calculator.rb` | 117 | method → unit 选择 |
| `src/scanner.rb` | 348 | method → ScanItem 构造 |
| `src/scanner.rb` | 433-687 | `compute_linear_length` 138 行硬编码三条路径 |
| `src/workbench_presenter.rb` | 148 | method → 量纲累加 |
| `src/workbench_presenter.rb` | 208 | 多 method 共存时主显选择 |
| `src/ui/js/model_view.js` | — | 前端按 method 显示 |

**加一种 method 要改 6 个文件，加一种"同 method 不同算法"无处可挂**。

### 解决思路

```
                ┌─────────────────────┐
   ScanItem ───►│  TakeoffPolicy      │── 返回 Strategy 对象
                │  4 档决议            │   (不再返回 :method 枚举)
                └─────────────────────┘
                          │
                          ▼
                ┌─────────────────────┐
                │  TakeoffStrategy    │── 封装 method + unit
                │  - emit_from_container
                │  - aggregate
                │  - matches?           ← 自动匹配规则
                └─────────────────────┘
                          │
                          ▼ 内部组装
                ┌─────────────────────┐
                │  LengthCalculator   │── 具体几何算法
                │  - EdgeBased        │   一个 Strategy 可换不同算法
                │  - VolumeBased      │
                │  - Baseline         │
                │  - Path             │← 新算法 = 新类，不改老代码
                └─────────────────────┘
```

### 用户感知

完全不变：

- 材质映射表：仍然填 `material/category/unit/spec`
- 组件映射表：仍然填 `material/category/unit/counting_method`
- 参数管理页：仍然配图层规则、标签定义、启发式
- AttrDict：仍然标 `method: length` 或 `tag: xxx`

策略由系统自动推出（命名约定 → 单位 → 图层 → 启发）。

```ruby
# src/strategies/base.rb
module SuTakeoff
  module Strategies
    # 算量策略抽象基类。
    #
    # 每个具体策略封装一种"算量方式"，包含：
    #   - method: 量纲（:area/:length/:volume/:count/:skip）
    #   - default_unit: 显示单位字符串
    #   - emit_from_container(entity, ctx): 容器级策略从 SU 实体产出 ScanItem
    #     （面级策略返回 nil，由 Scanner 走默认的收集子面流程）
    #   - aggregate(items, ctx): Presenter 用，把多条 ScanItem 累加成最终量
    class Base
      attr_reader :name, :method, :default_unit

      def initialize(name:, method:, default_unit:)
        @name = name
        @method = method
        @default_unit = default_unit
      end

      # Scanner 侧：从一个 ComponentInstance/Group 产出一条 ScanItem。
      # 面级策略不需要从容器 emit，返回 nil（Scanner 走默认下钻流程）。
      def emit_from_container(_entity, _ctx)
        nil
      end

      # Presenter 侧：把同 (entity_id, su_material) 下的 items 累加成最终量。
      # ctx 提供辅助数据：opening_area_by_face 等。
      def aggregate(_items, _ctx)
        raise NotImplementedError, "#{self.class}#aggregate must be implemented"
      end
    end
  end
end
```

```ruby
# src/strategies/registry.rb
module SuTakeoff
  module Strategies
    # 策略注册中心（单例）。
    #
    # 内置策略在插件加载时（main.rb）批量注册。
    # 通过 default_for: 标记每个 method 的默认策略，供未自动匹配命中时兜底。
    class Registry
      class << self
        def register(strategy, default_for: nil)
          @strategies ||= {}
          @defaults   ||= {}
          @strategies[strategy.name] = strategy
          @defaults[default_for] = strategy if default_for
        end

        def get(name)
          @strategies ||= {}
          @strategies[name]
        end

        def default_for(method)
          @defaults ||= {}
          @defaults[method]
        end

        def all
          @strategies ||= {}
          @strategies.values
        end

        # 测试用：重置注册状态
        def reset!
          @strategies = {}
          @defaults = {}
        end
      end
    end
  end
end
```

```ruby
# src/strategies/face_area.rb
module SuTakeoff
  module Strategies
    class FaceArea < Base
      def initialize
        super(name: :face_area, method: :area, default_unit: 'm²')
      end

      def aggregate(items, ctx)
        opening_map = ctx[:opening_area_by_face] || {}
        items.sum do |i|
          deduction = opening_map[i.face_id] || 0.0
          [i.qty - deduction, 0.0].max
        end
      end
    end
  end
end
```

```ruby
    #
    # 每个具体算法实现 compute(entity, ctx) -> Float | nil

    #   baseline_id: AttrDict 中的 baseline_id
    #   edge_scale: 累积缩放因子（parent_scale × entity_scale）
    #   model_unit_to_m: 模型单位 → 米的换算系数
    #   debug: 是否输出调试日志
```

```ruby
# src/length_calculators/baseline.rb
module SuTakeoff
  module LengthCalculators
    # 优先使用用户在 AttrDict 标注的 baseline_id 边长度。
    class Baseline < Base
      def compute(_entity, ctx)
        baseline_id = ctx[:baseline_id]
        return nil unless baseline_id
        edges = ctx[:entities] || []
        edge = find_edge_by_id(edges, baseline_id.to_i)
        return nil unless edge
        edge.length.to_f * ctx[:model_unit_to_m] * ctx[:edge_scale]
      end

      private

      def find_edge_by_id(entities, target_id)
        entities.each do |e|
          return e if e.is_a?(Sketchup::Edge) && e.entityID == target_id
          if e.is_a?(Sketchup::Group)
            found = find_edge_by_id(e.entities, target_id)
            return found if found
          elsif e.is_a?(Sketchup::ComponentInstance)
            found = find_edge_by_id(e.definition.entities, target_id)
            return found if found
          end
        end
        nil
      end
    end
  end
end
```

```ruby
# src/length_calculators/volume_based.rb
module SuTakeoff
  module LengthCalculators
    # Solid 体积法：volume / 截面高 / 截面厚 = 长度。
    # 需要至少 2 个 ≥4 边的"截面候选"方向组（边长 0.001~0.1m）。
    #
    # 不适用时返回 nil（让 Chained 尝试下一个算法）。
    class VolumeBased < Base
      def compute(entity, ctx)
        # 测试支持：ctx[:volume_m3] 显式给体积；生产用 entity.volume × 单位
        vol_m3 = ctx[:volume_m3] ||
                 (entity.respond_to?(:volume) && entity.volume.is_a?(Numeric) && entity.volume > 0 ?
                  entity.volume * 1.6387e-5 * (ctx[:scale]**3) : nil)
        return nil unless vol_m3 && vol_m3 > 0

        edges = ctx[:edges] || []
        groups = edges.group_by { |e| e[:dkey] }
        group_info = groups.map { |dkey, es| [dkey, es.map { |e| e[:len] }.max, es.size] }
                           .sort_by { |_, m, _| m }
        short_meaningful = group_info.select { |_, m, cnt| cnt >= 4 && m >= 0.001 && m < 0.1 }
        return nil if short_meaningful.size < 2

        h_m = short_meaningful[0][1]
        t_m = short_meaningful[1][1]
        (vol_m3 / h_m / t_m).round(4)
      end
    end
  end
end
```

```ruby
# src/length_calculators/edge_based.rb
module SuTakeoff
  module LengthCalculators
    # 边线法：各方向取最长边累加（排除截面方向）。
    # 含非方条形检测分支（>5 个 ≥4 边的方向组 → 按 5× gap 累加）。
    class EdgeBased < Base
      def compute(_entity, ctx)
        edges = ctx[:edges] || []
        return nil if edges.empty?

        # 非方条形（圆柱/圆角）：>5 组 ≥4 边
        dir_groups = edges.group_by { |e| e[:dkey] }
        meaningful_groups = dir_groups.select { |_, es| es.size >= 4 }
        if meaningful_groups.size > 5
          return non_box_aggregate(meaningful_groups)
        end

        # 常规：各方向取最长，按 5× gap 截断截面方向
        group_maxes = dir_groups.map { |dkey, es| [dkey, es.map { |e| e[:len] }.max, es] }
                                .sort_by { |_, m, _| -m }
        long_groups = []
        last_max = nil
        group_maxes.each do |_, max, es|
          if last_max.nil? || (last_max / max) < 5
            long_groups << es
            last_max = max
          else
            break
          end
        end
        long_groups.map { |es| es.map { |e| e[:len] }.max }.sum.round(4)
      end

      private

      def non_box_aggregate(meaningful_groups)
        sorted_maxes = meaningful_groups.map { |_, es| es.map { |e| e[:len] }.max }.sort.reverse
        result = sorted_maxes.first || 0
        sorted_maxes.each_cons(2) do |prev, cur|
          break if prev / cur > 5
          result += cur
        end
        result.round(4)
      end
    end
  end
end
```

```ruby
module SuTakeoff
  module Strategies
    class Base
      attr_reader :name, :method, :default_unit, :match_rules

      def initialize(name:, method:, default_unit:, match_rules: {})
        @name = name
        @method = method
        @default_unit = default_unit
        @match_rules = match_rules
      end

      # 是否匹配此 item / context（用于自动决议）。
      # match_rules 支持：
      #   definition_name_includes: [String, ...] —— 组件定义名含任一关键字
      #   definition_name_pattern: Regexp —— 正则匹配
      #   layer: [String, ...] —— 图层名精确匹配
      #   unit: [String, ...] —— mapping 表中 unit 匹配
      def matches?(item, context = {})
        return false unless any_rule? # 无规则则不自动匹配
        rules = @match_rules
        return true if matches_definition_name?(rules, context)
        return true if matches_layer?(rules, item)
        return true if matches_unit?(rules, context)
        false
      end

      def emit_from_container(_entity, _ctx)
        nil
      end

      def aggregate(_items, _ctx)
        raise NotImplementedError
      end

      private

      def any_rule?
        @match_rules && !@match_rules.empty?
      end

      def matches_definition_name?(rules, context)
        name = context[:definition_name]
        return false unless name
        if (kws = rules[:definition_name_includes])
          return true if kws.any? { |k| name.include?(k) }
        end
        if (pat = rules[:definition_name_pattern])
          re = pat.is_a?(Regexp) ? pat : Regexp.new(pat.to_s)
          return true if name =~ re
        end
        false
      end

      def matches_layer?(rules, item)
        layers = rules[:layer]
        return false unless layers && item.layer_name
        layers.include?(item.layer_name)
      end

      def matches_unit?(rules, context)
        units = rules[:unit]
        return false unless units && context[:unit]
        units.include?(context[:unit])
      end
    end
  end
end
```

```ruby
    # 从 data/strategies.json 加载用户自定义策略，复用 base_strategy 的 aggregate / emit 实现。
    module Loader
      def self.load_from_file!(path)
        return unless File.exist?(path)
        data = JSON.parse(File.read(path))
        data.each do |name, spec|
          base_name = spec['base_strategy']&.to_sym
          base = Registry.get(base_name)
          next unless base   # 跳过无效引用
          rules = symbolize_keys(spec['match_rules'] || {})
          # 用 base 的同类（dup 并改 name + rules）
          variant = base.class.new
          variant.instance_variable_set(:@name, name.to_sym)
          variant.instance_variable_set(:@match_rules, rules)
          Registry.register(variant)
        end
      end

      def self.symbolize_keys(hash)
        hash.each_with_object({}) do |(k, v), out|
          out[k.to_sym] = v
        end
      end
    end
  end
end
```

注意：所有内置策略的 `initialize` 不接受 `match_rules:` 参数。Loader 用 `instance_variable_set` 强行注入，避免改每个内置策略的构造。

```ruby
def auto_match_strategy(item, hint_method)
  context = build_match_context(item, hint_method)
```

```ruby
def emit_solid_by_method(entity, path, transform, method, tags, effective_tag = nil)
  # 查 Strategy（优先自动匹配的，回退到 default）
  context = build_match_context_for_entity(entity, method)
  strategy = find_emitting_strategy(method, entity, context)
  
  # 构造 ScanItem 通用部分
  comp_path     = path.map { |c| c.respond_to?(:name) ? c.name : c.to_s }
  comp_path_ids = path.map { |c| c.respond_to?(:entityID) ? c.entityID : 0 } + [entity.entityID]
  bb            = entity.bounds
  scale         = [transform.xscale.abs, transform.yscale.abs, transform.zscale.abs].max
  dims_in       = [bb.width * scale, bb.height * scale, bb.depth * scale].sort
  w, h, d       = dims_in.map { |x| (x || 0) * 0.0254 }
  mat_name = (tags && tags[:material]) ||
             (entity.respond_to?(:material) && entity.material&.name) ||
             first_child_face_material(entity) ||
             container_definition_name(entity)
  bb_center_world = bb.center.transform(transform)
  z_center_m      = bb_center_world.z * 0.0254
  layer           = entity.layer && entity.layer.name
  item_tag        = (tags && tags[:tag]) || effective_tag

  case method
  when :length
    # 优先 Strategy.compute_length；否则走默认 Chained
    length_m = if strategy.respond_to?(:compute_length)
                 ctx = build_length_ctx(entity, scale)
                 ctx ? strategy.compute_length(entity, ctx) : nil
               else
                 compute_linear_length(entity, scale)
               end || d
    ScanItem.linear_solid(
      face_id: entity.entityID, su_material: mat_name,
      length: length_m.round(4), width: w.round(4), height: h.round(4), depth: h.round(4),
      layer_name: layer, component_path: comp_path, component_path_ids: comp_path_ids,
      z_center: z_center_m.round(4), tags: tags, tag: item_tag
    )
  when :volume
    # ...同原有逻辑
  when :count
    # ...同原有逻辑
  end
end

def find_emitting_strategy(method, entity, context)
  Strategies::Registry.all.each do |s|
    next if s.method != method
    next if s.name == Strategies::Registry.default_for(method)&.name
    return s if s.matches?(nil, context) # nil item: 容器级没有 ScanItem
  end
  Strategies::Registry.default_for(method)
end

def build_match_context_for_entity(entity, hint_method)
  def_name = container_definition_name(entity)
  {
    definition_name: def_name,
    hint_method: hint_method
  }
end
```

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 自动匹配命中错误，用户不知道为何算量变化 | Stage 3 已暴露 `strategies` 字段；前端可以加一个 console 调试开关显示策略名 |
| `instance_variable_set` 在 Loader 中是侵入性手段 | Stage 4.2 替代方案：让 Base 接受 `match_rules:` 参数，所有内置策略 super 时透传。如有 hot reload 需求再升级 |
| Strategy 增多导致 require 链冗长 | 可加自动加载：`Dir[File.join(__dir__, 'strategies/*.rb')].each { require _1 }` |
| 性能：Registry.all 每次 resolve 都遍历 | 测得超 100ms 再加 method-bucket 索引，目前实测不构成瓶颈 |
| 既有用户的 AttrDict 标签 `method: length` 仍工作 | Stage 3 保留 method 字段；Policy 收到 attr method 时找该 method 的 default strategy |
