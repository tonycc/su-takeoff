# 用户手册 —— 算量配置与建模规范

> 面向：设计师、算量员、模型整理人员
> 适用版本：P1-P4 + 云端同步首版已落地的 SU Takeoff
> 配套：`docs/算量优化方案.md`（设计依据）

---

## 1. 一句话速览

**几何由模型负责，规则由插件配置负责。**

插件按 4 档优先级判定每个面/构件该按什么方式计量：

```
1. SU 右键菜单打的标签（最高，跟模型一起保存）
       ↓
2. 图层规则（在设置页配「线条 → 长度」「砌体 → 体积」）
       ↓
3. 几何启发（极窄长面自动建议为线材，红行待确认）
       ↓
4. 材质映射的 unit（兜底，由材料本身的单位反推）
```

任意一档命中，下面就不再考虑。**用户能看见的规则才是规则**——隐藏的命名约定不会触发任何特殊行为。

---

## 2. 建模规范（最重要）

### 强烈推荐：容器化建模

**所有"线性构件"和"实体构件"都用 Group 或 ComponentInstance 包起来。**

| 构件类型 | 推荐建模 | 原因 |
|---|---|---|
| 踢脚线 / 顶角线 / 收边条 | Group，放「线条」图层 | 插件容器级整体量取，bbox 最长边 = 长度，**不下钻 6 面**，杜绝面累加问题 |
| 砌体墙 / 现浇柱梁 | Group，放「砌体」/「混凝土」图层 | 容器级走体积，自动调 `entity.volume` API |
| 灯具 / 开关 / 洁具 | Component，在「组件映射」页设为「整件」 | 直接计件数 |
| 普通墙面 / 地面 / 天花 | 散面即可 | 默认按面积，扣门窗洞口 |

### 最低要求：踢脚线绝不要画 6 面同材质的盒子

如果你必须画散面（不是 Group），请遵守：

- **薄板厚度 ≤ 50mm**：插件能识别背靠背两面是同一根条，自动去重一面
- **顶面/底面也只画必要的那一个**：插件不会自动消除"绕一圈把侧面、顶面、底面都涂上同一种木纹材质"的算重

最稳妥的做法仍然是：**包成 Group + 放到「线条」图层**。

### 不要依赖组件名

插件**不**通过组件名（如"踢脚线#1"）触发任何特殊规则。命名只用于显示。如果想让某个组件特殊处理，用图层规则或右键标签。

## 3. 设置页配置

打开 `Plugins → SU Takeoff → 材料统计`，左侧「设置」页。

### 3.1 图层 → 计量方式（核心配置）

```
图层名             计量方式
─────────────────────────
线条               长度 (length)
砌体               体积 (volume)
保温               体积 (volume)
吊顶龙骨           长度 (length)
```

凡是放在这些图层下的 **Group / ComponentInstance**，扫描时被整体识别，直接产出一条长度/体积记录，不下钻子面。**散面**也会被同样的图层规则覆盖，但配合启发式才能算准（见 3.3）。

操作：在表格底部输入图层名 + 选方式 + 「添加」。规则即时生效，下次扫描即应用。

### 3.2 单位词表

- **长度单位**：`m / mm / cm / dm / km` —— 凡映射 unit 落到此组的，按长度计
- **件数单位**：`个 / 件 / 套 / 组 / 台 / 只` —— 按件计
- **体积单位**：`m³ / m3 / L / 立方` —— 按体积计

可在设置页增删。这些词表决定材质映射 unit 在「兜底档」如何被理解。

### 3.3 几何启发 + 阈值

**几何启发开关**：打开后，没在图层规则、没打标签、不走 instance 的窄长面，会被识别为"待确认线材"，在「按材料」视图以橙色边框 + 「待确认 N」徽标提示，**但不会直接出量**。

**阈值面板**（仅在启发式开启时生效）：

| 阈值 | 默认 | 含义 |
|---|---:|---|
| 线材最小长宽比 | 15 | 长边/短边大于此值才可能是线材（防止正方形面误判） |
| 线材最大短边 (m) | 0.20 | 短边大于此值不算线材（防止 0.6m 宽的窗台板误判） |
| 竖直薄板配对最大间距 (m) | 0.05 | 散面踢脚线两个长立面的厚度容忍度 |
| 竖直薄板面积容差 | 0.02 | 薄板两面允许的面积差占比（2%） |

调小阈值 → 更保守，红行减少；调大阈值 → 更激进，可能误判。多数情况用默认值即可。

## 4. SU 右键菜单（每个对象单独覆盖）

在 SU 视口里**选中** face / Group / ComponentInstance，**右键**：

```
算量 ▸
   按面积计算（强制）
   按长度计算（强制）
   按体积计算（强制）
   不计入算量
   清除算量标签
```

点击后，标签写入对象的 `AttributeDictionary('su_takeoff')`，**跟随 SKP 文件保存**。下次扫描即生效，且优先级最高（覆盖图层规则、启发式、映射）。

适用场景：
- 例外构件：某根特殊形状的踢脚线不在「线条」图层 → 单独打 length 标签
- 临时排除：墙上某个装饰面不参与本次算量 → 打 skip
- 批量清除：选中一批对象 → 「清除算量标签」一键还原

## 5. 红行确认流程

### 触发条件

启发式判定（来源 = `:heuristic`）的 usage 会被前端染成橙色边框。常见情形：

- 散面踢脚线放在普通图层，被识别为窄长 → 待确认是否按长度计
- 短粗装饰条不满足启发式严格条件，落入材质映射兜底 → 不会染色

### 操作

「按材料」视图找到橙色行，操作列出现：

- **✓ 按长度** — 确认这些面按长度计，写 AttrDict
- **改面积** — 改判为面积，写 AttrDict
- **跳过** — 标记 skip，从结果消失

点击后插件会弹出确认框（显示影响多少个面），确认后立即重扫，红行升级为白行（变为显式判定 `source: :attr`）。

### 注意

- 确认结果**写入 entity 属性**，跟模型走，团队内所有人下次打开都已确认
- 想反悔：右键对象 → 算量 → 清除算量标签

## 6. 同材多算

同一种 SU 材质既可以按面积、又可以按长度算。典型：「爵士白」既贴大板（m²）又切窗台条（m）。

**触发方式**：

| 板材部分 | 条材部分 | 配置 |
|---|---|---|
| 普通图层 | 「线条」图层 | 图层规则触发条材按长度 |
| 普通图层 | 右键打 length 标签 | AttrDict 触发条材按长度 |

**结果**：「按组件」视图中同一材质会按 `m²` 和 `m` 分别汇总，面积、长度互不串味。

## 7. 体积计量

### 砌体墙 / 现浇构件

```
建模：Group + 放在「砌体」图层（或打 volume 标签）
扫描：插件自动调 SU 的 entity.volume 算出 m³
```

要求 Group 是 **manifold solid**（闭合实体）—— 在 SU 里选中 Group 看「实体信息」面板，应有「体积」字段。**不是闭合的回退到 bbox 估算**，会偏大但不会崩溃。

### 体积结果

体积项只输出几何用量本身，例如红砖墙或混凝土构件的 `m³`。当前工作台不再包含后续成本或工艺相关计算。

## 8. 云端同步

云端同步用于登录平台账号并把当前扫描结果按 SU 智能算量协议 v2 推送到平台。打开插件后会先校验登录状态；未登录时，扫描、映射、设置、定位和标签写入等功能都会保持锁定。登录成功后可使用本地插件功能；推送到平台还需要具备 `quantity:ingest` 权限。

### 8.1 使用前准备

推送前需要先完成三件事：

1. 在 `data/api_config.json` 中配置平台 API 地址。当前生产配置为 `https://gzzyai.com`。
2. 在「材料映射」页为所有要上传的材料填写「平台标签」。未映射材料或缺少平台标签时，插件会阻止推送。
3. 点击「扫描全部」生成本次算量结果。

### 8.2 登录

打开插件后会先进入独立登录页：

- 输入平台账号和密码后点击「登录」。
- 如果账号属于多个租户，页面会显示租户下拉框，选择租户后再次登录。
- 登录成功后会自动校验当前账号是否具备 `quantity:ingest` 权限；缺少权限时仍会保持登录状态，但推送按钮不可用。
- 登录成功后，左侧扫描、映射、组件映射、设置和云端同步页面会解锁。
- 退出登录会清理当前会话和系统安全存储中的 refresh token。

插件不会把密码或 token 写入模型属性、普通 JSON 文件或前端本地存储。

### 8.3 项目绑定

首次推送前，在「云端同步」页填写：

| 字段 | 说明 |
|---|---|
| 平台项目编号 | 必填，应与平台项目编号一致 |
| 项目名称 | 必填，首次创建算量单时使用 |
| 模型标识 | 插件自动生成，只读展示 |

项目绑定会写入当前 SKP 模型的 `su_takeoff_cloud` AttributeDictionary，随模型保存。修改项目编号表示重新绑定到另一个平台项目，下一次推送会生成新的幂等版本。

### 8.4 推送结果

点击「推送算量」后：

- 插件先在 SketchUp 主线程构建 payload。
- 网络上传在后台线程执行，避免长时间卡住 SU 界面。
- 成功后显示 `sheet_id` 和 `model_version_id`，并把最近同步结果写回模型属性。
- 网络错误、429 或 5xx 会自动有限重试；最终失败时，失败 payload 会保存到本地 outbox，便于后续排查或重试。

如果出现「推送前校验未通过」，按页面提示补齐项目编号、材料映射或平台材料标签后重新推送。

## 9. 常见问题

### Q1：踢脚线算量出来 24m，实际只有 8m

**原因**：散面建模 + 6 面同材质 + 没在「线条」图层。

**解决**（按推荐度排序）：
1. 选中踢脚线 → SU 内打包成 Group → 放到「线条」图层 → 重新扫描
2. 选中踢脚线 → 右键算量 → 按长度计算（强制）
3. 把「线条」加到设置页的图层规则，并确保踢脚线在该图层
4. 散面建模时确保前后立面薄板厚度 ≤ 50mm（启发式 + 竖直薄板去重会救一部分）

### Q2：「按材料」视图出现橙色待确认行，怎么处理

不要忽略它。这表示插件不确定该按面积还是长度算。

- 确实是线材（踢脚线/收边） → 点「✓ 按长度」
- 应是面材（启发式误判） → 点「改面积」
- 不参与算量 → 点「跳过」

确认后红行消失，下次扫描不再出现。

### Q3：体积算出来是 0 或负数

**原因**：构件不是闭合实体。常见情况：缺面、面法线翻转、边界没合上。

**解决**：在 SU 内选中 Group → 编辑组 → 检查所有面的法线（朝向应一致）→ 用「实体工具 → 实体外壳」修复，或重画。

修不了的情况下，插件会自动用 bbox 估算，结果偏大，建议手工核对。

### Q4：改了图层规则，结果没变

「保存」是即时的，但需要**重新扫描**。点左侧「扫描全部」。

### Q5：右键菜单没有「算量」选项

确认你**选中了** face / Group / ComponentInstance。空选 / 选中边线 / 选中辅助线时不会显示。

### Q6：想批量给一类对象打标签

SU 内框选多个对象 → 一次右键 → 「算量 → 按 X 计算」会一次性给所有选中对象写标签。

### Q7：误打的标签想批量清除

框选要清除的对象 → 右键 → 「算量 → 清除算量标签」。

### Q8：导出 CSV 在哪

「材料映射」管理页 → 顶部「导出 CSV」按钮。算量结果的导出在「按材料」视图（待补充）。

## 10. 推荐配置模板

新项目第一次配置时，建议在设置页录入这些图层规则：

```
线条           length
顶角线         length
踢脚线         length
窗帘盒         length
保温层         volume
砌体墙         volume
现浇构件       volume
回填土         volume
```

并打开「几何启发」开关，阈值用默认值。这样大多数装修住宅项目能开箱即用。

---

## 11. 何时需要写代码 / 找开发

- 新增计量维度（如重量 kg、面密度）
- 新的去重场景（如倾斜薄板、弧形线条）
- 修改启发式判定逻辑
- 新增工艺类型 / 派生公式语法

参考 `docs/算量优化方案.md` 的设计章节再决定。简单调阈值/规则**不需要**改代码，全在设置页搞定。
